Campus Route Finder

Find the shortest walking route between any two places on campus using Dijkstra's Algorithm.

Weighted GraphAdjacency ListPriority QueueO((V + E) log V)

About the Project

The campus is modelled as a weighted graph: every building is a vertex and every road is an edge whose weight is the walking distance in metres. Dijkstra's algorithm uses a min-heap priority queue to always process the closest unvisited place first.

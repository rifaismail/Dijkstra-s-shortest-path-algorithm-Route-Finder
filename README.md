# Campus Route Finder

Shortest path navigation on a college campus using **Dijkstra's Algorithm**
(Data Structures and Algorithms Mini Project, Module IV - Graphs).

- Graph stored as an adjacency list (linked list of edges)
- Binary min-heap used as the priority queue
- Time complexity O((V + E) log V)

## Files
| File | Purpose |
|------|---------|
| `index.html` | Website with an interactive step-by-step Dijkstra visualizer |
| `campus_route_finder.c` | C source code (compile in Dev C++ or `gcc campus_route_finder.c -o crf`) |
| `output.txt` | Sample program output |
| `output_screenshot.png` | Output screenshot |
